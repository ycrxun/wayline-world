完成阅读不一定要用一个普通的“已读”按钮结束。

Wayline World 会在文章阅读进度达到阈值后开放“完成阅读”，然后用文章标签生成徽章。重复标签会去重，最终收藏保存在浏览器的 `localStorage` 中。

## 为什么是标签

标签原本就是文章的最小语义单元。把它们变成收藏物，比按照文章数量累计积分更接近内容本身。

同一次阅读可能获得多枚徽章，也可能只获得已经拥有的徽章。系统会明确区分“新发现”和“已收藏”。
